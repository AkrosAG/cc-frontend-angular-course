## Modul 5

In der App-Component existiert eine Variable "todos" vom Typ `TodoItem[]`
1. Füge in der Todo-Component einen Input "todos" hinzu, mit demselben Typ `TodoItem[]`
2. Übergebe die todos Variable der App-Component an die Todo-Component 
3. Erweitere das Template der Todo-Component um eine Liste, die die Todos darstellt. 
4. Wenn die todos Variable leer ist, soll der Text "Keine Einträge" angezeigt werden.
